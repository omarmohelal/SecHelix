# SecHelix 3.2.0-alpha.1

Repository cleanup, packaging normalization, security depth, trust hardening, and
a set of gates that stop the documentation from drifting away from the code.

Alpha software. Public benchmark status remains `NOT_MEASURED`.

## Packaging

The root `SKILL.md` made the Skills CLI treat the whole repository as the skill,
so `npx skills add` installed 354 files and 5.1 MB — tests, evals, CI config, and
a recursive copy of `skills/`. It is gone. The canonical entry point is
`skills/sechelix/SKILL.md`, installs are **1.67 MB**, and
`scripts/validate_skill.py` fails if a root `SKILL.md` reappears.

The specialist-agent index moved out of `agents/`, where it was being loaded as
an 18th agent. The plugin marketplace moved to `omarmohelal/sechelix-marketplace`,
because co-locating it shadowed plugin validation.

Always-on plugin cost is ~1,107 tokens for one skill and 17 specialist agents.

## Security depth

| Module | What it does |
| --- | --- |
| `untrusted_repo.py` | Under `UNTRUSTED_REPO`, repository content is data and never control. `CLAUDE.md`, `AGENTS.md`, settings, hooks and docstrings cannot grant a capability or widen scope. Trust resolution fails closed. |
| `diff_review.py` | Classifies a change as `NEW_RISK`, `RISK_REDUCED`, `UNCHANGED` or `UNKNOWN` across 18 delta rules. |
| `attack_chains.py` | Composes verified findings into five named chains. Only `VERIFIED` findings compose; severity comes from the composed outcome, never from raising a component. |
| `revision.py` | Binds a report to the tree it inspected. The gate exits `2 INCOMPLETE` rather than reusing a report describing a different commit. |
| `patch_mode.py` | Emits a `.patch` and a `.md` rationale for verified findings. Never applies anything. |
| `variant_rules.py` | Turns a verified finding into a Semgrep rule. Rules are `UNVALIDATED` until run; hits are `HYPOTHESIS` at `INFO`. |

All six are reachable from `SKILL.md`, which previously referenced none of them.

**Six framework Gold Packs** (12 → 18): Next.js App Router, Express/Node, Django,
Supabase/PostgREST, Spring Boot, Laravel. Each carries 10–12 false-positive
filters written as refutation guidance — what evidence shows the code is *safe* —
and states version boundaries where a default changed rather than assuming one.

**`docs/reference/ai-agent-security.md`** covers prompt injection, tool authority,
MCP server trust and description poisoning, the `list_changed` rug pull, excessive
agency, exfiltration paths, retrieval, memory poisoning, multi-agent delegation,
output sinks, and AI supply chain, each with how to verify and how to refute. It
ends by saying what does not work: filtering, blocklists, delimiters alone,
self-policing, and MCP annotations — which the specification itself says are hints
clients should never base critical decisions on.

## Evidence

The eval suite is **38 paired fixtures / 76 cases across 10 families**. The
knowledge graph is 76 nodes, 100 edges, 11 lesson cards.

The keyword baseline is now reproducible in one command and stamped with its
commit, suite version, and a SHA-256 of the exact case file. It had been scored
against the 19-fixture suite and never regenerated, so the published number had
silently become a measurement of a suite that no longer existed. Rescored:
**precision 0.511, recall 0.632**, false-positive rate 0.605. The precision is a
coin flip and the recall is bought by flagging 47 of 76 cases. Still
`is_sechelix_result: false`.

`evals/blind-packet/` lets an uncontaminated evaluator run without repository
access. Benchmarks remain `NOT_MEASURED` with the `CONTAMINATED_EVALUATOR`
blocker recorded machine-readably.

## New gates

Three classes of defect shipped this cycle were invisible to every existing
check, so each has a gate now.

- **`scripts/check_doc_consistency.py`** reads counts from the tree and fails when
  prose disagrees. The suite grew and the packs quadrupled while the README, the
  launch drafts and the research reports went on stating old numbers, and nothing
  caught it. Documents that record a dated snapshot declare it with a visible
  marker.
- **`tests/test_skill_references.py`** asserts every `sechelix_core` symbol named
  in `SKILL.md` imports and exists. `SKILL.md` had documented
  `diff_review.classify_changes`, which never existed.
- **`scripts/check_local_links.py`** now reports a code fence that is never
  closed. Masking is faithful to CommonMark, which is the problem: everything
  after an open fence stops rendering *and* stops being checked, both silently.

## Discoverability

`.github/skills/sechelix/SKILL.md` ships, because GitHub documents that path for
Copilot and the README already claimed it existed. Status is `DOCUMENTED`, not
`VERIFIED` — no Copilot session was observed loading it.

There is deliberately no `.codex/skills/` mirror. The README claimed one, it never
existed, and this project's own compatibility matrix says not to rely on that
path. The row now reads `NOT_SHIPPED`.

`docs/research/discovery-baseline.md` records a measured starting point: **6
queries, 0 found**, including the project's own name.

## Fixed

- Chain signals matched on a leading word boundary only, so "event listener"
  satisfied a bulk-access link and "runtime error" satisfied pipeline execution.
- Three signals were written as prefixes and could never match after the boundary
  fix, so the textbook account-takeover case reported `POTENTIAL` instead of
  `CONFIRMED`.
- A chain was demoted from `CONFIRMED` when any unverified finding shared a signal
  word with any link, even one already carried by a verified finding.
- `score()` dropped `result_kind` and `is_sechelix_result`, which would have
  published an unlabelled number. Both now default to `UNDECLARED`.
- Patch mode accepted finding ids resolving to Windows device names, and did not
  enforce the output-directory confinement it documented.
- The adapters were described as 9 in several places; the registry holds 11.

## Verification

235 unit tests, 19 adapter tests. `validate_catalog`, `validate_skill`,
`validate_knowledge`, `validate_gold_packs`, `check_local_links`,
`check_doc_consistency` and `check_install_snippets` all pass, and the portable
bundle was exercised from a copy outside the repository.

## Known limitations

- Public benchmark is `NOT_MEASURED`. One case study is not a performance claim.
- Codex and Copilot loading are `DOCUMENTED`, never observed here.
- Framework pack coverage is six frameworks; the eval corpus stays
  framework-neutral, so the packs are not measured by it.
- The trophy case is empty on purpose.
