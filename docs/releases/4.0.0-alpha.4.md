# SecHelix 4.0.0-alpha.4

**Date:** 2026-09-09  
**Maturity:** public alpha  
**Portable Agent Skill:** still works without the optional runtime  
**Optional Python runner:** `0.3.0`, unchanged  
**Blind label evaluation:** `MEASURED`  
**Full SecHelix workflow:** `NOT_MEASURED`

A metadata release. **No behaviour changed**: the action's inputs, outputs,
steps, decision logic and fail-closed semantics are byte-for-byte what
`4.0.0-alpha.3` shipped.

## The Marketplace listing was rejected on a length limit

Publishing the action to GitHub Marketplace returned:

> Description must be less than 125 characters.

The `action.yml` description was **188**. Nothing about the action was wrong —
the metadata simply could not be published, and a folded YAML scalar hides its
true length from anyone counting lines rather than characters.

**Before** (188 characters):

> Evidence-first security review for a repository or pull request. Reports PASS,
> PASS_WITH_KNOWN_RISK, BLOCKED or INCOMPLETE, and never renders a run that
> examined nothing as a clean result.

**After** (113 characters):

> Evidence-first AppSec review for repositories and pull requests, with verified
> findings and fail-closed outcomes.

The outcome vocabulary the old description spelled out is unchanged behaviour and
is documented in [`docs/github-action.md`](../github-action.md). Shortening a
listing string must not quietly drop the semantics it carried, so a test asserts
those words still appear in the docs.

## Four tests so this cannot recur

`tests/test_plugin_manifests.py::ActionMarketplaceMetadata` asserts:

- the description is **under 125 characters** — confirmed red against the old
  188-character string and green against the new one;
- the description is a **single line**, because a folded scalar disguises its
  length;
- `name` is present and `branding.color` is one of the eight colours Marketplace
  accepts, alongside an `icon`;
- the outcome vocabulary dropped from the description still lives in the docs.

There was no way to discover the limit from CI before this. Now there is.

## Unchanged

Everything else is `4.0.0-alpha.3`: the root-level GitHub Action, the official
MCP Registry entry, the containerised MCP adapter, the reproducible
`examples/expense-api` demo. The optional Python runner stays at `0.3.0` —
nothing in it changed.

The full SecHelix workflow remains `NOT_MEASURED`.
