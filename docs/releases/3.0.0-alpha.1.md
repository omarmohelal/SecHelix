# SecHelix 3.0.0-alpha.1

SecHelix VNext turns the evidence-first methodology into an executable,
contract-driven AppSec framework while keeping its core promise: verify before
you accuse.

## Highlights

- 546 explicit and stable hypothesis IDs across 21 security families.
- Eight JSON Schema Draft 2020-12 contracts from authorized scope to canonical
  report.
- Deterministic four-state applicability with fail-closed scope handling.
- Seventeen specialist role profiles and an independent refutation pass.
- Normalized evidence adapters for major static, dependency, secret, browser,
  passive web, and template-driven security tools.
- One canonical report rendered to Markdown, redacted JSON, SARIF 2.1.0, and
  escaped standalone HTML.
- Public default/strict policy packs, audit/retention guidance, and signed
  evidence-bundle design.
- A self-contained Agent Skills distribution verified through a cold copied
  install.

## Honest benchmark status

Eight paired vulnerable/clean fixture families and a blind-export path now
exist. Aggregate capability and model-role rows remain `NOT_MEASURED`. This
release does not claim that one model, provider, or scanner is best.

## Safety and compatibility

Dynamic adapters are bounded by explicit execution modes. ZAP is passive by
default, Nuclei requires safe profiles and allowlisting, and malformed or
incomplete reports fail closed. Private organization policy remains outside the
public framework. The product website source remains separate from this public
repository.

## Verification snapshot

- 54 core/repository tests passed.
- 19 adapter/agent-profile tests passed.
- 546 catalog entries, 21 families, and 26 lenses validated.
- Skill, schemas, local links, install snippets, secrets, and public/private
  separation checks passed.

This is an alpha contract release: schemas and report semantics are ready for
design-partner feedback, but may still evolve before 3.0.0 stable.
