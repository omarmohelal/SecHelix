# SecHelix 3.0.0-alpha.4

This alpha closes the V2 Pro product-polish and public-preview pass while
preserving the private website-source boundary.

## Product experience

- interactive verification console with verified, refuted, and incomplete
  fixture states;
- Evidence Workbench covering hypothesis, evidence, independent verification,
  root cause, remediation, regression proof, and release gate;
- Attack Surface digital twin, Authorization Matrix, Variant Analysis, honest
  Benchmark Lab, and Cmd/Ctrl+K Command Center;
- mobile application navigation, larger technical copy, visible focus, and
  reduced-motion support.

## Framework truth

- 546 explicit hypotheses across 21 families and 26 lenses;
- 17 specialist roles;
- 15 JSON contracts, including Gold Check Packs;
- one authorization reference pack and deterministic Variant Hunter foundation;
- aggregate benchmark status remains `NOT_MEASURED`.

## Release hygiene

- obsolete preview images and generated QA output were replaced or removed;
- public screenshots contain no private source, source maps, credentials, or
  local filesystem paths;
- the private site and public framework retain separate repositories and
  validation gates.
