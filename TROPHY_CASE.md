# SecHelix Trophy Case

SecHelix only lists findings that have **public, attributable evidence** and permission to be referenced.

A large number of findings is not the goal. High-signal verified security improvements are.

## Reporting a result

Open a trophy-case issue with:

- the public project/repository;
- the SecHelix version/commit used;
- the security surface;
- a public advisory, issue, PR, or fix reference;
- whether attribution is permitted;
- no secrets, customer data, or live exploit material.
